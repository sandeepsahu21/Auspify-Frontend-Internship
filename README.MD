# Auspify Technologies – Frontend Development Internship

This repository contains four projects completed as part of my Frontend Development Internship at Auspify Technologies.

The objective of these tasks was to develop practical frontend skills, build responsive user interfaces, understand JavaScript functionality, and work with React.js.

## Completed Tasks

### Task 1: Landing Page

**Description:** Developed a responsive landing page with a modern user interface and mobile-friendly layout.

**Key Features:**
- Responsive design for desktop, tablet, and mobile.
- Structured sections and navigation.
- Modern styling and user-friendly interface.

**Technologies:** HTML5, CSS3, JavaScript

### Task 2: Portfolio 

**Description:** Created a personal portfolio website to showcase skills, projects, and professional information.

**Key Features:**
- Interactive portfolio sections.
- About, Skills, Projects, and Contact sections.
- Responsive user interface.
- Smooth navigation and user interactions.

**Technologies:** HTML5, CSS3, JavaScript

### Task 3: To-Do App

**Description:** Built a dynamic To-Do application to manage daily tasks using JavaScript and DOM manipulation.

**Key Features:**
- Add new tasks.
- Delete existing tasks.
- Mark tasks as completed.
- Save tasks using Local Storage.
- Dynamic DOM manipulation and event handling.

**Technologies:** HTML5, CSS3, JavaScript, Local Storage

### Task 6: Modern Web Dashboard

**Description:** Developed a modern and responsive analytics dashboard using React.js and Tailwind CSS.

**Key Features:**
- Dashboard with analytics cards.
- Revenue analytics chart.
- Traffic sources visualization.
- Recent orders table.
- Search and status filtering.
- Export orders to CSV.
- Responsive sidebar and navigation.
- Reusable React components.

**Technologies:** React.js, JavaScript, Tailwind CSS, Recharts, Lucide React, Vite

## Installation and Setup

For React-based projects:

1. Clone this repository.
2. Navigate to the required project folder.
3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

For HTML, CSS and JavaScript projects, open the `index.html` file in your browser.
